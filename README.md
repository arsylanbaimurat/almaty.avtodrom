# ПДД автодром — Алматы (ProPDD)

Тренажёр практического экзамена на автодроме спецЦОН №1, Саялы. Работает в браузере на компьютере и на телефоне, ничего устанавливать не нужно.

**Играть:** https://arsylanbaimurat.github.io/almaty.avtodrom/

## Управление

| Компьютер | Действие |
|---|---|
| W или ↑ | газ |
| S или ↓ | тормоз, с места — назад |
| A D или ← → | руль |
| R | передача D / R вручную |
| Q / E | левый / правый поворотник |
| H | аварийка |
| B | ремень |
| Пробел | ручник |
| C | вид: за машиной / сверху |
| V | зеркала вкл / выкл |
| Esc | пауза |

На телефоне — кнопки на экране.

## Упражнения

1. Старт
2. Пешеходный переход
3. Крутой подъём и спуск
4. Железнодорожный переезд
5. Змейка
6. Аварийная остановка
7. Разворот и парковка в бокс
8. Регулируемый перекрёсток
9. Параллельная парковка задним ходом
10. Финиш

100 штрафных баллов — экзамен не сдан.

> Это учебный тренажёр, а не официальная программа экзамена. Порядок упражнений и размеры площадок могут отличаться от реального автодрома — сверяйтесь с инструктором.
